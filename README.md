# 架空路線図メーカー

架空鉄道の路線図エディタ兼シミュレーターです。iPhone（Safari）と Windows PC（Chrome / Edge）のブラウザで動く静的サイトで、GitHub Pages で公開しています。

- 公開URL：https://miyoshigo-cpu.github.io/rail-map-maker/
- 仕様：[SPEC.md](SPEC.md)

> 現在はフェーズ2（種別・運行系統・直通運転）までできています。見た目の書き出し、地形、シミュレーションはこのあとのフェーズで作ります。

## 使い方

### はじめる

1. 公開URLを開き、「新しいプロジェクト」を押します。テンプレートで「サンプル（架空の都市圏）」を選ぶと、見本の路線図から始められます。一覧の「サンプルを開く」でも見られます。
2. 「駅」を選んで画面の格子をタップすると駅を置けます。駅名とよみ（ひらがな）を入れると、英字が自動で入ります（例：しんばし → Shimbashi）。
3. 「路線」を選んで駅を順にタップすると路線になります。何もない所をタップすると駅も一緒に作ります。「完了」か、最後の駅のダブルタップで終わります。始点の駅をタップすると環状線にできます。
4. 線や駅をタップすると、右（スマホでは下）のパネルで色・路線記号・駅番号・ランクなどを変えられます。

### 主な操作

| やりたいこと | 操作 |
|---|---|
| 駅を動かす | 「選択」で駅をドラッグ（格子にそろう） |
| 複数の駅を選ぶ | PC：Shift＋ドラッグ、Ctrl＋クリック ／ スマホ：右上の点線の四角を押してからドラッグ |
| 駅をそろえる | 複数選んで、パネルの「横一列」「縦一列」「斜め一列」「等間隔」 |
| 分岐・乗換グループ・駅名の位置 | 駅を長押し（PC は右クリック） |
| 駅の挿入・曲がり位置・区間の削除 | 線を長押し（PC は右クリック） |
| 駅番号を付ける | 路線のパネル →「駅ナンバリング」→「駅番号を付ける」 |
| 表で編集・並べ替え | 「データ」（営業キロ・駅の並び・並走の順番もここ） |
| 問題を探す | 「チェック」 |
| 駅を探す | 「⋯」→「駅を検索」（PC は Ctrl+F） |
| 種別を作る | 事業者のパネルの「まとめて追加」（普通・快速・急行などのプリセット）。データ表の「種別」で編集・並べ替え |
| 運行系統を作る | 「データ」→「系統」→「系統を追加」で始発駅と終着駅を選び、経路の候補を押す（ほかの会社の路線への直通運転もできる） |
| 停車駅・本数を変える | 系統のパネル（区間ごとの種別、停車駅のチェック、時間帯別の本数、両数）。所要時間と表定速度も出る |
| 停車駅案内図を見る | 上の「案内図」（PC は横、スマホは縦に並ぶ） |
| 取り消す・やり直す | ↶ ↷（PC は Ctrl+Z／Ctrl+Y） |

キーボードの操作の一覧は、アプリの「⋯」→「ヘルプ」にあります。

### 保存とバックアップ

- データはこの端末のブラウザの中（IndexedDB）に自動で保存されます。サーバーには送りません。
- ときどき「書き出す」（スマホは「⋯」→「書き出す」）で JSON ファイル（`名前_日時.railmap.json`）にバックアップしてください。最後のバックアップから7日たつと、画面の上で案内します。
- バックアップは、プロジェクト一覧の「ファイルから読み込む」で戻せます（いまあるプロジェクトは上書きしません）。
- 大きな操作の前と、編集中は10分ごとに「復元ポイント」を自動で作ります。プロジェクト一覧の「⋯」→「復元ポイント」から戻せます。

### iPhone で使うときの注意

- Safari の「共有」→「ホーム画面に追加」で、アプリのように起動できます。
- ホーム画面に追加したアプリと Safari は、保存場所が別々です。移すときは JSON で書き出して、もう一方で読み込んでください。
- Safari はしばらく開かないサイトのデータを消すことがあります。定期的に JSON で書き出してください。

## ローカルで動かす（開発用）

ES Modules を使っているため、`index.html` をダブルクリックして開いても動きません。ローカルサーバーを起動してください。

Windows（PowerShell）で、このフォルダに移動してから：

```
py tools/serve.py
```

ブラウザで http://localhost:8000/ を開きます。止めるときは Ctrl+C です。

- `tools/serve.py` は `python -m http.server` と同じですが、ブラウザにキャッシュさせないので、ファイルを編集したあと再読み込みするだけで反映されます。
- このPCでは `python` コマンドが使えないため `py` を使っています。
- 同じネットワークの iPhone からは `http://（PCのIPアドレス）:8000/` で開けます。開けないときは、Windows のファイアウォールで Python の「プライベート」ネットワークでの通信を許可してください。

### テスト

- ブラウザ：サーバーを起動して http://localhost:8000/tests/ を開く
- Node.js：`npm test`

### 補助スクリプト

- `node tools/check-i18n.js`：画面の文言がカタログ（`js/i18n/`）を通っているか、日本固有の値が地域パックの外にないか、パスの大文字小文字が合っているかを検査します。
- `node tools/make-sample.js`：サンプル（`samples/sample-metro.railmap.json`）を作り直します。
- `node tools/make-icons.js`：アイコン画像（`icons/`）を作り直します。
- `node tools/browser-check.js`：入っている Chromium を画面なしで動かし、画面写真・コンソールのエラー・ブラウザのテストの結果を確かめます（画面を直接見られない環境向け）。
- 性能確認：URL の末尾に `?debug=1` を付けて開くと、プロジェクト一覧に「性能確認用のデータを作る（駅200・路線20）」が出ます。

## 公開のしかた（GitHub Pages）

1. main ブランチに push します。
2. GitHub のリポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を「main」「/ (root)」にして保存します（最初の1回だけ）。
3. 数分後に公開URLで開けるようになります。

## 作りの概要

- ビルド不要。HTML・CSS・JavaScript（ES Modules）だけで、外部ライブラリは使いません。
- `js/core/`：画面に依存しない処理（テスト対象）。データの型（`schema.js`）、Undo/Redo（`store.js`・`patch.js`）、八方向の線（`octilinear.js`）、並走（`parallel.js`）、英字（`romaji.js`）、駅番号（`numbering.js`）、チェック（`validate.js`）、営業キロ（`distance.js`）、運行系統（`services.js`・`network.js`・`runtime.js`）、停車駅案内図（`stopchart.js`）など
- `js/core/regions/`：地域パック（日本の鉄道の決まりごと。§3.2 の既定値や種別のプリセット）
- `js/render/`：路線図と停車駅案内図の表示リストの作成（駅名の配置を含む）と Canvas での描画
- `js/ui/`：画面と操作（ツール・パネル・データ表・チェック・検索・設定）
- `js/storage/`：保存（IndexedDB）、自動保存、書き出し・読み込み、復元ポイント
- `js/i18n/`：画面の文言（日本語カタログ）
